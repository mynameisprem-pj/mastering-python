## 📚 1. What is Python?
Python is a high-level, free, and open-source programming language developed by **Guido van Rossum**. 

**Key Features:**
- Simple and easy to learn syntax.
- Portable across different operating systems.
- Code is executed using an **Interpreter** to translate high-level code to machine code.
