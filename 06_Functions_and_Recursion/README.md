# Lecture 6: Functions & Recursion ⚙️

Welcome to **Lecture 6** of the Python learning series! This directory covers modular programming using **User-Defined Functions**, **Default Parameters**, built-in functions, and **Recursion**.

---

## 🧠 Concepts Covered

### 1. Functions in Python
* **Definition:** A block of reusable statements designed to perform a specific task.
* **Syntax:** Defined using the `def` keyword, accepting parameters, and returning values via `return`.
* **Arguments vs Parameters:** Parameters are variables declared in the function definition; arguments are the actual values passed during a function call.

### 2. Built-in vs User-Defined Functions
* **Built-in Functions:** Functions provided directly by Python, such as `print()`, `len()`, `type()`, and `range()`.
* **User-Defined Functions:** Custom functions created by programmers to perform specific operations.

### 3. Default Parameters
* Assigning a default value to a parameter, which gets used automatically if no argument is passed during the function call.
* Non-default parameters must always precede default parameters in the function header.

### 4. Recursion
* **Definition:** A technique where a function calls itself repeatedly to solve a problem.
* **Base Case:** The condition that terminates recursion to prevent infinite function calls.
* **Recursive Step:** The step where the function calls itself with modified parameters (e.g., `fact(n-1)`).
