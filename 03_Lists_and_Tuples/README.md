# Lecture 3: Lists & Tuples 🐍

Welcome to **Lecture 3** of the Python learning series! This directory contains code examples, practice exercises, and summary notes covering Python's sequence data types: **Lists** (mutable) and **Tuples** (immutable).

---

## 🧠 Concepts Covered

### 1. Lists in Python
* **Definition:** A built-in data type that stores a collection of items (can store mixed data types like integers, floats, strings).
* **Mutability:** Unlike strings, list elements **can** be changed using index assignment (e.g., `student[0] = "Arjun"`).
* **Length:** Calculated using `len(list_name)`.
* **List Slicing:** Extracts parts of a list using `list[start:end]` or negative indices.

### 2. Common List Methods
* `append(val)`: Adds an element at the end of the list.
* `sort()`: Sorts the list in ascending order.
* `sort(reverse=True)`: Sorts the list in descending order.
* `reverse()`: Reverses the current order of elements.
* `insert(idx, val)`: Inserts an element at a specific index.
* `remove(val)`: Removes the first occurrence of a value.
* `pop(idx)`: Removes the element at the specified index.

### 3. Tuples in Python
* **Definition:** Built-in data type used to create **immutable** sequences of values.
* **Syntax:** Enclosed in parentheses `(val1, val2)`. Single-element tuples require a trailing comma `(1,)`.
* **Immutability:** Reassigning elements (e.g., `tup[0] = 43`) is **not allowed**.

### 4. Common Tuple Methods
* `index(val)`: Returns the index of the first occurrence of a value.
* `count(val)`: Counts the total occurrences of a value in the tuple.
