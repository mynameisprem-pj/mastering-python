## 🧠 Concepts Covered

### 1. Strings & Basic Operations
* **Definition:** Strings store sequences of characters[cite: 1].
* **Concatenation:** Combining strings using the `+` operator (e.g., `"hello" + "world"` $\rightarrow$ `"helloworld"`)[cite: 1].
* **Length:** Calculating string length using `len(str)`[cite: 1].

### 2. Indexing & Slicing
* **Indexing:** Accessing specific characters by index (0-based)[cite: 1]. Strings are immutable, so direct assignment (e.g., `str[0] = 'X'`) is not allowed[cite: 1].
* **Positive Slicing:** Extracting substrings via `str[start:end]` (ending index is excluded)[cite: 1].
* **Negative Indexing & Slicing:** Accessing characters from the end of a string using negative indices[cite: 1].

### 3. Built-in String Functions
* `str.endswith(suffix)`: Checks if a string ends with a specific substring[cite: 1].
* `str.capitalize()`: Capitalizes the first character[cite: 1].
* `str.replace(old, new)`: Replaces occurrences of a substring[cite: 1].
* `str.find(substring)`: Returns the first index of a matching substring[cite: 1].
* `str.count(substring)`: Counts the total occurrences of a substring[cite: 1].

### 4. Conditional Statements
* **Syntax:** `if`, `elif`, and `else` blocks[cite: 1].
* **Flow Control:** Executing code blocks based on specific boolean conditions[cite: 1].
